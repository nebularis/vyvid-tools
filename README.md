# Vyvid Tools Domain

Вивід: домен інструментів розробника

This domain holds notes on how to do things with the tools a developer uses, kept so that any project can use them. It has one register.

- `notes.md` holds one note `NOTE-n` per finding, on `mise`, `uv`, and `cabal` with `ghc`. A note says what to do and why, and its Evidence cell says what was run and on which version.

A note holds for the versions and the platform it names and no others, until it is run again. A project keeps a register of the same type in its own documents and names a note of this domain in its Specialises column, so a question asked in that project is answered with the project's row first and the note beneath it.
